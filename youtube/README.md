# मिल्की शॉर्ट्स — Milky YouTube Shorts

Ready-to-shoot storyboard site for the Hindi comedy Shorts starring **Milky** the dog,
for [@chamanrastogi](https://www.youtube.com/@chamanrastogi).

## Files

| File | What it is |
|---|---|
| `index.html` | The site. Bootstrap 5.3 (CDN) + Google Fonts (Anton, Mukta) + `style.css`. |
| `style.css` | Theme layer: design tokens + component styles. |
| `design.md` | **Design source of truth** (tokens, type, layout, signature, a11y). |
| `project.md` | What the project is, how to run and extend it. |
| `README.md` | This file. |

## Open it

No build step. Double-click `index.html`, or:

```
npx serve .
```

## What's on the page

- Hero with the film-title wordmark and Milky's title card
- Storyboard — 3 shots with visual, Hindi dialogue, on-screen caption, and sound
- Shoot directions (look, audio, acting)
- Copy-ready AI video prompt
- Hashtags

## Ground rules

- Natural conversational Hindi; no emojis in content.
- 10–15 second Shorts; hook first, punchline last.
- Milky acts the comedy — reactions over long dialogue.
